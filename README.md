# 338 生物化学 · 可视化学习工作台

一个面向 **广东药科大学硕士研究生招生考试 338《生物化学》** 的交互式可视化学习网页。

项目以考试大纲为学习范围边界，并以姚文兵主编《生物化学》第 9 版的知识体系作为主要参考，用于帮助理解生物化学中较为抽象的代谢过程、酶动力学与分子生物学过程。

## 功能

目前主要包含：

- 总代谢地图
- 糖代谢动态学习
- 酶动力学模拟
- DNA 复制、RNA 转录与蛋白质翻译可视化
- 考纲重点模式
- 自测模式
- 知识点搜索与详情查看
- 学习状态记录

项目主要用于辅助理解和主动回忆，而不是替代教材、课程及正式考试资料。

## 学习范围

考试范围以广东药科大学公布的 **338《生物化学》考试大纲** 为准。

参考教材：

> 姚文兵主编，《生物化学》，人民卫生出版社。

本项目的知识内容主要按照第 9 版体系整理，同时针对考试大纲规定的范围进行取舍。

本项目仅作为个人学习辅助工具，内容可能存在疏漏，不应作为唯一考试依据。
